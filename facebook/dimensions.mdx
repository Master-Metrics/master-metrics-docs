Esta referencia cubre las 33 dimensiones disponibles de Facebook Pages en Master Metrics. Úsala para entender cómo puedes segmentar tus datos y cómo se llama cada campo.

**Disponible en:** Dashboards · Reportes · Asistente de IA · MCP

## Dimensiones

Las dimensiones son los atributos que puedes usar para segmentar y agrupar tus datos de Facebook Pages.

### Página

| | |
|---|---|
| Nombre de la página | **Nombre del campo:** `PAGE_NAME`<br/>**Tipo:** dimensión |
| ID de la página | **Nombre del campo:** `PAGE_ID`<br/>**Tipo:** dimensión |
| Idioma | **Nombre del campo:** `LANGUAGE`<br/>**Tipo:** dimensión |
| Género y edad (Deprecado) | **Nombre del campo:** `GENDERAGE`<br/>**Tipo:** dimensión |
| Género (Deprecado) | **Nombre del campo:** `GENDER_Deprecated`<br/>**Tipo:** dimensión |
| Edad (Deprecado) | **Nombre del campo:** `AGE_Deprecated`<br/>**Tipo:** dimensión |
| Tipo de publicación | **Nombre del campo:** `POST_TYPE`<br/>**Tipo:** dimensión |
| Tipo de medio de la publicación | **Nombre del campo:** `POST_MEDIA_TYPE`<br/>**Tipo:** dimensión |
| Tipo de acción | **Nombre del campo:** `ACTION_TYPE`<br/>**Tipo:** dimensión |

### Audiencia

| | |
|---|---|
| Ciudad | **Nombre del campo:** `CITY`<br/>**Tipo:** dimensión |
| País | **Nombre del campo:** `COUNTRY`<br/>**Tipo:** dimensión |

| | |
|---|---|
| Nombre de la publicación | **Nombre del campo:** `POST_NAME`<br/>**Tipo:** dimensión |

| Mensaje de la publicación | **Nombre del campo:** `POST_MESSAGE`<br/>**Tipo:** dimensión |
| Imagen de la publicación | **Nombre del campo:** `POST_PICTURE`<br/>**Tipo:** dimensión |
| Imagen y título de la publicación | **Nombre del campo:** `POST_PICTURE_TITLE`<br/>**Tipo:** dimensión |
| URL permanente de la publicación | **Nombre del campo:** `POST_PERMALINK_URL`<br/>**Tipo:** dimensión |
| Fecha de creación de la publicación | **Nombre del campo:** `POST_CREATED_TIME`<br/>**Tipo:** dimensión |
| Estado de la publicación | **Nombre del campo:** `POST_STATUS_TYPE`<br/>**Tipo:** dimensión |
