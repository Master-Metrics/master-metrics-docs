Esta referencia cubre las 8 métricas disponibles de Google Search Console en Master Metrics. Úsala para entender qué datos puedes obtener y cómo se llama cada campo.

**Disponible en:** Dashboards · Reportes · Asistente de IA · MCP

## Métricas

Las métricas son los valores numéricos que puedes medir y agregar a partir de tus datos de Google Search Console.

### Rendimiento de búsqueda

| | |
|---|---|
| Impresiones | **Nombre del campo:** `gsc_impressions`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Clics | **Nombre del campo:** `gsc_clicks`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| CTR | **Nombre del campo:** `gsc_ctr`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Posición promedio | **Nombre del campo:** `gsc_position`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Palabras en la consulta de búsqueda | **Nombre del campo:** `gsc_words_in_query_met`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |

### Sitemaps

| | |
|---|---|
| URLs enviadas | **Nombre del campo:** `gsc_submitted`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Advertencias | **Nombre del campo:** `gsc_warnings`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Errores | **Nombre del campo:** `gsc_errors`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
