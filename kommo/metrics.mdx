Esta referencia cubre las 8 métricas disponibles de Kommo en Master Metrics. Úsala para entender qué datos puedes obtener y cómo se llama cada campo.

**Disponible en:** Dashboards · Reportes · Asistente de IA · MCP

## Métricas

Las métricas son los valores numéricos que puedes medir y agregar a partir de tus datos de Kommo.

### Leads

| | |
|---|---|
| Cantidad de leads | **Nombre del campo:** `lead_count`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Valor de Leads $ | **Nombre del campo:** `won_leads_acc_price`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Tiempo promedio de venta | **Nombre del campo:** `avg_lead_sales_time`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Tiempo promedio de cierre | **Nombre del campo:** `avg_lead_close_time`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
