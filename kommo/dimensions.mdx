Esta referencia cubre las 17 dimensiones disponibles de Kommo en Master Metrics. Úsala para entender cómo puedes segmentar tus datos y cómo se llama cada campo.

**Disponible en:** Dashboards · Reportes · Asistente de IA · MCP

## Dimensiones

Las dimensiones son los atributos que puedes usar para segmentar y agrupar tus datos de Kommo.

### Tiempo

| | |
|---|---|
| Día | **Nombre del campo:** `day`<br/>**Tipo:** dimensión |
| Semana | **Nombre del campo:** `week`<br/>**Tipo:** dimensión |
| Mes | **Nombre del campo:** `month`<br/>**Tipo:** dimensión |
| Año | **Nombre del campo:** `year`<br/>**Tipo:** dimensión |
| Trimestre | **Nombre del campo:** `quarter`<br/>**Tipo:** dimensión |
| ID del usuario responsable | **Nombre del campo:** `responsible_user_id`<br/>**Tipo:** dimensión |
| Nombre del usuario responsable | **Nombre del campo:** `responsible_user_name`<br/>**Tipo:** dimensión |

### Leads

| | |
|---|---|
| (Lead) Etiquetas | **Nombre del campo:** `lead_tags`<br/>**Tipo:** dimensión |
| ID del estado | **Nombre del campo:** `status_id`<br/>**Tipo:** dimensión |
| Estado del lead | **Nombre del campo:** `status_name`<br/>**Tipo:** dimensión |
| ID del pipeline | **Nombre del campo:** `pipeline_id`<br/>**Tipo:** dimensión |
| Nombre del pipeline | **Nombre del campo:** `pipeline_name`<br/>**Tipo:** dimensión |
| Motivo de pérdida | **Nombre del campo:** `loss_reason`<br/>**Tipo:** dimensión |
| Origen del lead | **Nombre del campo:** `lead_source`<br/>**Tipo:** dimensión |

### Contactos

### Empresas
