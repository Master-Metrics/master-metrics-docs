Esta referencia cubre las 42 dimensiones disponibles de WooCommerce en Master Metrics. Úsala para entender cómo puedes segmentar tus datos y cómo se llama cada campo.

**Disponible en:** Dashboards · Reportes · Asistente de IA · MCP

## Dimensiones

Las dimensiones son los atributos que puedes usar para segmentar y agrupar tus datos de WooCommerce.

### General

| | |
|---|---|
| Día | **Nombre del campo:** `day`<br/>**Tipo:** dimensión |
| Semana | **Nombre del campo:** `week`<br/>**Tipo:** dimensión |
| Mes | **Nombre del campo:** `month`<br/>**Tipo:** dimensión |
| Trimestre | **Nombre del campo:** `quarter`<br/>**Tipo:** dimensión |
| Año | **Nombre del campo:** `year`<br/>**Tipo:** dimensión |
| Nombre de la tienda (Común) | **Nombre del campo:** `woocommerce_shop_name`<br/>**Tipo:** dimensión |
| ID de la tienda (Común) | **Nombre del campo:** `woocommerce_shop_id`<br/>**Tipo:** dimensión |
