<Info>**Última actualización:** 2026-11-12</Info>

Esta referencia cubre las 87 métricas disponibles de Shopify en Master Metrics. Úsala para entender qué datos puedes obtener y cómo se llama cada campo.

**Disponible en:** Dashboards · Reportes · Asistente de IA · MCP

## Métricas

Las métricas son los valores numéricos que puedes medir y agregar a partir de tus datos de Shopify.

### Clientes

| | |
|---|---|
| Cantidad (Clientes) | Cantidad de clientes de la tienda.<br/><br/>**Nombre del campo:** `shopify_customers_count`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |

### Carritos abandonados

| | |
|---|---|
| Cantidad (Carritos abandonados) | Cantidad de checkouts abandonados.<br/><br/>**Nombre del campo:** `shopify_abandonedCheckouts_count`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Monto total (Carritos abandonados) | Monto total de los checkouts abandonados.<br/><br/>**Nombre del campo:** `shopify_abandonedCheckouts_total_amount`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |

| Total de comisiones (Pedidos) | Cargos adicionales cobrados en los pedidos.<br/><br/>**Nombre del campo:** `shopify_orders_fees`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Total de Descuentos (Pedidos) | Descuentos totales aplicados a los productos de los pedidos.<br/><br/>**Nombre del campo:** `shopify_orders_discounts`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Costo de Envío (Pedidos) | Envío cobrado en los pedidos.<br/><br/>**Nombre del campo:** `shopify_orders_original_price`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Total de Impuestos y Aranceles (Pedidos) | Aranceles cobrados en los pedidos.<br/><br/>**Nombre del campo:** `shopify_orders_duties`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Precio total (Pedidos) | Precio total actual de los pedidos, después de ediciones y reembolsos.<br/><br/>**Nombre del campo:** `shopify_orders_price`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Precio promedio (Pedidos) | Valor promedio del pedido: ventas divididas por la cantidad de pedidos.<br/><br/>**Nombre del campo:** `shopify_orders_average_price`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Subtotal total (Pedidos) | Precio de los pedidos después de descuentos, antes de envío e impuestos.<br/><br/>**Nombre del campo:** `shopify_orders_subtotal_price`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Impuestos (Pedidos) | Impuestos cobrados en los pedidos.<br/><br/>**Nombre del campo:** `shopify_orders_tax`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Devoluciones (Pedidos) | Valor de los productos devueltos.<br/><br/>**Nombre del campo:** `shopify_orders_returns_total`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Impuestos de Devoluciones (Pedidos) | Impuestos de los productos devueltos.<br/><br/>**Nombre del campo:** `shopify_orders_returns_taxes`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Ventas netas (Pedidos) | Ventas netas: ventas brutas menos descuentos y devoluciones. Sin envío ni impuestos.<br/><br/>**Nombre del campo:** `shopify_orders_net_sales_total`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Ventas totales (Pedidos) | Ventas totales: ventas netas más envío, impuestos, aranceles y cargos.<br/><br/>**Nombre del campo:** `shopify_orders_total_sales`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Artículos Netos Vendidos (Pedidos) | Artículos netos vendidos: unidades vendidas menos unidades devueltas. Usar para productos vendidos.<br/><br/>**Nombre del campo:** `shopify_orders_net_items_sold`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |

| Margen Bruto (Pedidos) | Margen bruto: ganancia bruta como porcentaje de las ventas netas con costo cargado.<br/><br/>**Nombre del campo:** `shopify_orders_gross_margin`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Ganancia Bruta (Pedidos) | Ganancia bruta: ventas netas de productos con costo cargado menos su costo.<br/><br/>**Nombre del campo:** `shopify_orders_gross_profit`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Monto Gastado por Cliente (Pedidos) | Monto promedio gastado por cliente.<br/><br/>**Nombre del campo:** `shopify_orders_amount_spent_per_customer`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Paquetes Pedidos (Pedidos) | Cantidad de paquetes de productos pedidos.<br/><br/>**Nombre del campo:** `shopify_orders_bundles_ordered`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Clientes (Pedidos) | Cantidad de clientes que hicieron pedidos.<br/><br/>**Nombre del campo:** `shopify_orders_customers`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Descuentos Devueltos (Pedidos) | Descuentos revertidos por devoluciones.<br/><br/>**Nombre del campo:** `shopify_orders_discounts_returned`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Descuentos de Tarjeta de Regalo (Pedidos) | Descuentos aplicados a tarjetas de regalo.<br/><br/>**Nombre del campo:** `shopify_orders_gift_card_discounts`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Ventas Brutas de Tarjeta de Regalo (Pedidos) | Ventas brutas de tarjetas de regalo.<br/><br/>**Nombre del campo:** `shopify_orders_gift_card_gross_sales`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Ventas Netas de Tarjeta de Regalo (Pedidos) | Ventas netas de tarjetas de regalo.<br/><br/>**Nombre del campo:** `shopify_orders_gift_card_net_sales`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |

| Devoluciones Brutas (Pedidos) | Valor bruto de los productos devueltos.<br/><br/>**Nombre del campo:** `shopify_orders_gross_returns`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
