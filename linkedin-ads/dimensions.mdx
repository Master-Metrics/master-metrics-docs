Esta referencia cubre las 33 dimensiones disponibles de LinkedIn Ads en Master Metrics. Úsala para entender cómo puedes segmentar tus datos y cómo se llama cada campo.

**Disponible en:** Dashboards · Reportes · Asistente de IA · MCP

## Dimensiones

Las dimensiones son los atributos que puedes usar para segmentar y agrupar tus datos de LinkedIn Ads.

### General

| | |
|---|---|
| Nombre de la cuenta | **Nombre del campo:** `ACCOUNT_NAME`<br/>**Tipo:** dimensión |
| ID de la cuenta | **Nombre del campo:** `ACCOUNT_ID`<br/>**Tipo:** dimensión |
| Nombre de la campaña | **Nombre del campo:** `CAMPAIGN_NAME`<br/>**Tipo:** dimensión |
| Estado de la campaña | **Nombre del campo:** `CAMPAIGN_STATUS`<br/>**Tipo:** dimensión |
| ID de la campaña | **Nombre del campo:** `CAMPAIGN_ID`<br/>**Tipo:** dimensión |
| Tipo de campaña | **Nombre del campo:** `CAMPAIGN_TYPE`<br/>**Tipo:** dimensión |
| Nombre del grupo de campaña | **Nombre del campo:** `CAMPAIGN_GROUP_NAME`<br/>**Tipo:** dimensión |
| Estado del grupo de campaña | **Nombre del campo:** `CAMPAIGN_GROUP_STATUS`<br/>**Tipo:** dimensión |
| ID del grupo de campaña | **Nombre del campo:** `CAMPAIGN_GROUP_ID`<br/>**Tipo:** dimensión |
| Industria | **Nombre del campo:** `MEMBER_INDUSTRY`<br/>**Tipo:** dimensión |
| Nombre de la conversión | **Nombre del campo:** `CONVERSION_NAME`<br/>**Tipo:** dimensión |
| ID de la conversión | **Nombre del campo:** `CONVERSION_ID`<br/>**Tipo:** dimensión |
| Tipo de conversión | **Nombre del campo:** `CONVERSION_TYPE`<br/>**Tipo:** dimensión |
| Conversión habilitada | **Nombre del campo:** `CONVERSION_ENABLED`<br/>**Tipo:** dimensión |
| Tamaño de empresa | **Nombre del campo:** `MEMBER_COMPANY_SIZE`<br/>**Tipo:** dimensión |
| Antigüedad | **Nombre del campo:** `MEMBER_SENIORITY`<br/>**Tipo:** dimensión |
| Puesto de trabajo | **Nombre del campo:** `MEMBER_JOB_TITLE`<br/>**Tipo:** dimensión |
| Función laboral | **Nombre del campo:** `MEMBER_JOB_FUNCTION`<br/>**Tipo:** dimensión |
| País | **Nombre del campo:** `MEMBER_COUNTRY_V2`<br/>**Tipo:** dimensión |
| Regiones | **Nombre del campo:** `MEMBER_REGION_V2`<br/>**Tipo:** dimensión |
| Empresa | **Nombre del campo:** `MEMBER_COMPANY`<br/>**Tipo:** dimensión |
