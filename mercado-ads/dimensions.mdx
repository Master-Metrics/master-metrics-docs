Esta referencia cubre las 20 dimensiones disponibles de Mercado Ads en Master Metrics. Úsala para entender cómo puedes segmentar tus datos y cómo se llama cada campo.

**Disponible en:** Dashboards · Reportes · Asistente de IA · MCP

## Dimensiones

Las dimensiones son los atributos que puedes usar para segmentar y agrupar tus datos de Mercado Ads.

### Tiempo

| | |
|---|---|
| Día | **Nombre del campo:** `day`<br/>**Tipo:** dimensión |
| Semana | **Nombre del campo:** `week`<br/>**Tipo:** dimensión |
| Mes | **Nombre del campo:** `month`<br/>**Tipo:** dimensión |
| Trimestre | **Nombre del campo:** `quarter`<br/>**Tipo:** dimensión |
| Año | **Nombre del campo:** `year`<br/>**Tipo:** dimensión |

### General

| | |
|---|---|
| ID de cuenta | **Nombre del campo:** `mercadoads_account_id`<br/>**Tipo:** dimensión |
| Nombre de la cuenta | **Nombre del campo:** `mercadoads_account_name`<br/>**Tipo:** dimensión |
