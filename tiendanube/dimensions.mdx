Esta referencia cubre las 150 dimensiones disponibles de Tiendanube en Master Metrics. Úsala para entender cómo puedes segmentar tus datos y cómo se llama cada campo.

**Disponible en:** Dashboards · Reportes · Asistente de IA · MCP

## Dimensiones

Las dimensiones son los atributos que puedes usar para segmentar y agrupar tus datos de Tiendanube.

### Tiempo

| | |
|---|---|
| Día | **Nombre del campo:** `day`<br/>**Tipo:** dimensión |
| Semana | **Nombre del campo:** `week`<br/>**Tipo:** dimensión |
| Mes | **Nombre del campo:** `month`<br/>**Tipo:** dimensión |
| Año | **Nombre del campo:** `year`<br/>**Tipo:** dimensión |
| Trimestre | **Nombre del campo:** `quarter`<br/>**Tipo:** dimensión |

### General

| | |
|---|---|
| Nombre de la tienda | Nombre de la tienda.<br/><br/>**Nombre del campo:** `tn_common_store_name`<br/>**Tipo:** dimensión |
| ID de la tienda | **Nombre del campo:** `tn_common_store_id`<br/>**Tipo:** dimensión |
| Tipo de entidad | Tipo de registro: pedido, producto de pedido, producto, cliente o carrito abandonado.<br/><br/>**Nombre del campo:** `tn_common_type_entity`<br/>**Tipo:** dimensión |
