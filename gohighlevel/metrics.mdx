Esta referencia cubre las 7 métricas disponibles de GoHighLevel en Master Metrics. Úsala para entender qué datos puedes obtener y cómo se llama cada campo.

**Disponible en:** Dashboards · Reportes · Asistente de IA · MCP

## Métricas

Las métricas son los valores numéricos que puedes medir y agregar a partir de tus datos de GoHighLevel.

### Contactos

| | |
|---|---|
| Cantidad (Contactos) | **Nombre del campo:** `ghl_contact_count`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |

| | |
|---|---|
