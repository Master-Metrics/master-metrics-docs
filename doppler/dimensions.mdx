Esta referencia cubre las 22 dimensiones disponibles de Doppler en Master Metrics. Úsala para entender cómo puedes segmentar tus datos y cómo se llama cada campo.

**Disponible en:** Dashboards · Reportes · Asistente de IA

## Dimensiones

Las dimensiones son los atributos que puedes usar para segmentar y agrupar tus datos de Doppler.

### Tiempo

| | |
|---|---|
| Día | **Nombre del campo:** `day`<br/>**Tipo:** dimensión |
| Semana | **Nombre del campo:** `week`<br/>**Tipo:** dimensión |
| Mes | **Nombre del campo:** `month`<br/>**Tipo:** dimensión |
| Año | **Nombre del campo:** `year`<br/>**Tipo:** dimensión |
| Trimestre | **Nombre del campo:** `quarter`<br/>**Tipo:** dimensión |
| ID de cuenta | **Nombre del campo:** `doppler_account_id`<br/>**Tipo:** dimensión |

### Campañas

| | |
|---|---|
| Fecha de envío de la campaña | **Nombre del campo:** `doppler_campaign_send_date`<br/>**Tipo:** dimensión |
| Nombre de la campaña | **Nombre del campo:** `doppler_campaign_name`<br/>**Tipo:** dimensión |
| Id de la campaña | **Nombre del campo:** `doppler_campaign_id`<br/>**Tipo:** dimensión |
| Segmento de la campaña | **Nombre del campo:** `doppler_campaign_segment`<br/>**Tipo:** dimensión |
| Lista de la campaña | **Nombre del campo:** `doppler_campaign_list`<br/>**Tipo:** dimensión |
| URL del enlace de la campaña | **Nombre del campo:** `doppler_campaign_link_url`<br/>**Tipo:** dimensión |
| Asunto de la campaña | **Nombre del campo:** `doppler_campaign_subject`<br/>**Tipo:** dimensión |
| Email del remitente de la campaña | **Nombre del campo:** `doppler_campaign_sender_email`<br/>**Tipo:** dimensión |
| Etiquetas de la campaña | **Nombre del campo:** `doppler_campaign_tags`<br/>**Tipo:** dimensión |
