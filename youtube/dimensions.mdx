Esta referencia cubre las 40 dimensiones disponibles de YouTube en Master Metrics. Úsala para entender cómo puedes segmentar tus datos y cómo se llama cada campo.

**Disponible en:** Dashboards · Reportes · Asistente de IA · MCP

## Dimensiones

Las dimensiones son los atributos que puedes usar para segmentar y agrupar tus datos de YouTube.

### Tiempo

| | |
|---|---|
| Día | **Nombre del campo:** `day`<br/>**Tipo:** dimensión |
| Semana | **Nombre del campo:** `week`<br/>**Tipo:** dimensión |
| Mes | **Nombre del campo:** `month`<br/>**Tipo:** dimensión |
| Año | **Nombre del campo:** `year`<br/>**Tipo:** dimensión |
