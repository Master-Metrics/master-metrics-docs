Esta referencia cubre las 23 métricas disponibles de YouTube en Master Metrics. Úsala para entender qué datos puedes obtener y cómo se llama cada campo.

**Disponible en:** Dashboards · Reportes · Asistente de IA · MCP

## Métricas

Las métricas son los valores numéricos que puedes medir y agregar a partir de tus datos de YouTube.

### Canal

| | |
|---|---|
| Total de visualizaciones del canal | **Nombre del campo:** `youtube_channel_views`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Total de suscriptores del canal | **Nombre del campo:** `youtube_channel_subscribers`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Total de videos del canal | **Nombre del campo:** `youtube_channel_videos`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Suscriptores ganados | **Nombre del campo:** `youtube_subscribersGained`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Suscriptores perdidos | **Nombre del campo:** `youtube_subscribersLost`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Minutos estimados vistos | **Nombre del campo:** `youtube_estimatedMinutesWatched`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Proporción de visualización de la audiencia | **Nombre del campo:** `youtube_audienceWatchRatio`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Visualizaciones | **Nombre del campo:** `youtube_views`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
