This reference covers the 23 metrics available for YouTube in Master Metrics. Use it to understand which data you can pull and how each field is named.

**Available in:** Dashboards · Reports · AI assistant · MCP

## Metrics

Metrics are the numeric values you can measure and aggregate from your YouTube data.

### Channel

| | |
|---|---|
| Channel total views count | The number of times the channel has been viewed (all time).<br/><br/>**Field name:** `youtube_channel_views`<br/>**Type:** metric<br/>**MCP:** Available |
| Channel total subscribers | The number of subscribers that the channel has (all time).<br/><br/>**Field name:** `youtube_channel_subscribers`<br/>**Type:** metric<br/>**MCP:** Available |
| Channel total videos | The number of public videos uploaded to the channel (all time). Note that the value reflects the count of the channel's public videos only.<br/><br/>**Field name:** `youtube_channel_videos`<br/>**Type:** metric<br/>**MCP:** Available |
| Gained subscribers | The number of times that users subscribed to a channel.<br/><br/>**Field name:** `youtube_subscribersGained`<br/>**Type:** metric<br/>**MCP:** Available |
| Lost subscribers | The number of times that users unsubscribed from a channel.<br/><br/>**Field name:** `youtube_subscribersLost`<br/>**Type:** metric<br/>**MCP:** Available |
| Estimated minutes watched | The number of minutes that users watched videos for the specified channel, content owner or video.<br/><br/>**Field name:** `youtube_estimatedMinutesWatched`<br/>**Type:** metric<br/>**MCP:** Available |
| Audience watch ratio | The absolute ratio of viewers watching the video at the given point in the video.<br/><br/>**Field name:** `youtube_audienceWatchRatio`<br/>**Type:** metric<br/>**MCP:** Available |
| Views | Number of times a video was viewed.<br/><br/>**Field name:** `youtube_views`<br/>**Type:** metric<br/>**MCP:** Available |
| Comments | Number of comments left by users on a video.<br/><br/>**Field name:** `youtube_comments`<br/>**Type:** metric<br/>**MCP:** Available |
| Likes | Number of times users indicated they liked a video by clicking the like button.<br/><br/>**Field name:** `youtube_likes`<br/>**Type:** metric<br/>**MCP:** Available |
| Dislikes | Number of times users indicated they disliked a video by clicking the dislike button.<br/><br/>**Field name:** `youtube_dislikes`<br/>**Type:** metric<br/>**MCP:** Available |
| Shares | Number of times users shared a video.<br/><br/>**Field name:** `youtube_shares`<br/>**Type:** metric<br/>**MCP:** Available |
| Videos added to playlist | The number of times that videos were added to any YouTube playlists.<br/><br/>**Field name:** `youtube_videosAddedToPlaylists`<br/>**Type:** metric<br/>**MCP:** Available |
| Videos removed to playlist | The number of times that videos were added to any YouTube playlists.<br/><br/>**Field name:** `youtube_videosRemovedFromPlaylists`<br/>**Type:** metric<br/>**MCP:** Available |
| Average view duration | The average length, in seconds, of video playbacks.<br/><br/>**Field name:** `youtube_averageViewDuration`<br/>**Type:** metric<br/>**MCP:** Available |
| Average view duration percentage | The average percentage of a video watched during a video playback.<br/><br/>**Field name:** `youtube_averageViewPercentage`<br/>**Type:** metric<br/>**MCP:** Available |
| Viewer percentage | The percentage of viewers who were logged in when watching the video.<br/><br/>**Field name:** `youtube_viewerPercentage`<br/>**Type:** metric<br/>**MCP:** Available |

### Videos

| | |
|---|---|
| Video total views | The number of views that the video has (all time). .<br/><br/>**Field name:** `youtube_video_views`<br/>**Type:** metric<br/>**MCP:** Available |
| Video total likes | The number of likes that the video has (all time). .<br/><br/>**Field name:** `youtube_video_likes`<br/>**Type:** metric<br/>**MCP:** Available |
| Video total dislikes | The number of dislikes that the video has (all time). .<br/><br/>**Field name:** `youtube_video_dislikes`<br/>**Type:** metric<br/>**MCP:** Available |
| Video total favorites | The number of favorites that the video has (all time). .<br/><br/>**Field name:** `youtube_video_favorites`<br/>**Type:** metric<br/>**MCP:** Available |
| Video total comments | The number of comments that the video has (all time). .<br/><br/>**Field name:** `youtube_video_comments`<br/>**Type:** metric<br/>**MCP:** Available |
| Channel video counts | The number of public videos uploaded to the channel (all time). Note that the value reflects the count of the channel's public videos only.<br/><br/>**Field name:** `youtube_channel_videos_counts`<br/>**Type:** metric<br/>**MCP:** Available |
