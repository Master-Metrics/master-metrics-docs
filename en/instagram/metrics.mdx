This reference covers the 68 metrics available for Instagram in Master Metrics. Use it to understand which data you can pull and how each field is named.

**Available in:** Dashboards · Reports · AI assistant · MCP

## Metrics

Metrics are the numeric values you can measure and aggregate from your Instagram data.

### Account

| | |
|---|---|
| Profile Followers | Total followers of the account (day by day). Use it for total followers; split by age range, gender or location (country/city) it gives the followers' demographics.<br/><br/>**Field name:** `instagram_follower_demographics`<br/>**Type:** metric<br/>**MCP:** Available |
| Views | Total number of times the account's content (posts, reels and stories) was played or displayed during the selected period (its accumulated views).<br/><br/>**Field name:** `instagram_views`<br/>**Type:** metric<br/>**MCP:** Available |
| Profile reach | Number of unique accounts that saw the account's content at least once during the selected period (its accumulated reach), including content from ads. For ranges over 30 days, 30-day periods are added up, so some accounts may be counted more than once.<br/><br/>**Field name:** `instagram_profile_reach`<br/>**Type:** metric<br/>**MCP:** Available |
| Profile new follows | Number of new accounts that followed the profile during the selected period.<br/><br/>**Field name:** `instagram_profile_new_follows`<br/>**Type:** metric<br/>**MCP:** Available |
| Media Engagement | Calculated engagement (likes plus comments) generated by feed and reels media.<br/><br/>**Field name:** `instagram_media_engagement`<br/>**Type:** metric<br/>**MCP:** Available |
| Media carousel engagement | Calculated engagement (likes plus comments) generated by carousel album posts.<br/><br/>**Field name:** `instagram_media_carousel_engagement`<br/>**Type:** metric<br/>**MCP:** Available |
| Profile Follows | Number of accounts the profile follows ("following"), not its followers. For total followers use instagram_follower_demographics.<br/><br/>**Field name:** `instagram_profile_follows_count`<br/>**Type:** metric<br/>**MCP:** Available |
| Profile media count | Total content the account has published since it was created (all-time, does not depend on the selected period). Use it for the account's total content or total posts.<br/><br/>**Field name:** `instagram_profile_media_count`<br/>**Type:** metric<br/>**MCP:** Available |

### Media

| | |
|---|---|
| Media count | Content (posts, reels...) published during the selected period. For the account's all-time total use instagram_profile_media_count.<br/><br/>**Field name:** `instagram_media_count`<br/>**Type:** metric<br/>**MCP:** Available |
| Media paid impressions | Number of times the boosted (promoted) post was on screen.<br/><br/>**Field name:** `instagram_media_paid_impressions`<br/>**Type:** metric<br/>**MCP:** Available |
| Media paid spend | Estimated total amount spent on boosting (promoting) the post.<br/><br/>**Field name:** `instagram_media_paid_spend`<br/>**Type:** metric<br/>**MCP:** Available |
| Media paid reach | Number of unique accounts that saw the boosted (promoted) post at least once.<br/><br/>**Field name:** `instagram_media_paid_reach`<br/>**Type:** metric<br/>**MCP:** Available |
| Media paid clicks | Number of clicks generated by the boosted (promoted) post.<br/><br/>**Field name:** `instagram_media_paid_clicks`<br/>**Type:** metric<br/>**MCP:** Available |
| Media paid post interactions | Number of engagement actions (post_engagement: likes, comments, shares and clicks) generated by boosting the post.<br/><br/>**Field name:** `instagram_media_paid_post_interactions`<br/>**Type:** metric<br/>**MCP:** Available |
| Media paid link click | Number of clicks on links included in the boosted (promoted) post.<br/><br/>**Field name:** `instagram_media_paid_link_click`<br/>**Type:** metric<br/>**MCP:** Available |
| Media paid like | Number of likes generated by boosting (promoting) the post.<br/><br/>**Field name:** `instagram_media_paid_like`<br/>**Type:** metric<br/>**MCP:** Available |
| Media paid comment | Number of comments generated by boosting (promoting) the post.<br/><br/>**Field name:** `instagram_media_paid_comment`<br/>**Type:** metric<br/>**MCP:** Available |
| Media paid share | Number of times the post was shared as a result of boosting (promoting) it.<br/><br/>**Field name:** `instagram_media_paid_share`<br/>**Type:** metric<br/>**MCP:** Available |
| Media paid video view | Number of video views generated by boosting (promoting) the post.<br/><br/>**Field name:** `instagram_media_paid_video_view`<br/>**Type:** metric<br/>**MCP:** Available |
| Media like count | Number of likes on the media object.<br/><br/>**Field name:** `instagram_media_like_count`<br/>**Type:** metric<br/>**MCP:** Available |
| Media likes | Number of likes on the media object.<br/><br/>**Field name:** `instagram_media_likes`<br/>**Type:** metric<br/>**MCP:** Available |
| Media comments | Number of comments on the media object.<br/><br/>**Field name:** `instagram_media_comments`<br/>**Type:** metric<br/>**MCP:** Available |
| Media comments count | Number of comments on the media object.<br/><br/>**Field name:** `instagram_media_comments_count`<br/>**Type:** metric<br/>**MCP:** Available |
| Media Reach | Number of unique accounts that have seen the media at least once.<br/><br/>**Field name:** `instagram_media_reach`<br/>**Type:** metric<br/>**MCP:** Available |
| Media Video Reach | Number of unique accounts that have seen the video media at least once.<br/><br/>**Field name:** `instagram_media_videwo_reach`<br/>**Type:** metric<br/>**MCP:** Available |
| Media saved | Number of times the media was saved by Instagram users.<br/><br/>**Field name:** `instagram_media_saved`<br/>**Type:** metric<br/>**MCP:** Available |
| Media Total Interactions | Number of likes, saves, comments and shares on the media, minus unlikes, unsaves and deleted comments.<br/><br/>**Field name:** `instagram_media_total_interactions`<br/>**Type:** metric<br/>**MCP:** Available |
| Media Shares | Number of times the media was shared.<br/><br/>**Field name:** `instagram_media_shares`<br/>**Type:** metric<br/>**MCP:** Available |

## Deprecated metrics

These metrics were retired by the platform. They are kept for historical reference and are not available in the MCP.

| | |
|---|---|
| Profile impressions | Total number of times the account's posts, stories, reels and videos were on screen, including impressions from ads. Deprecated by Meta in favor of 'views'.<br/><br/>**Field name:** `instagram_impressions`<br/>**Type:** metric<br/>**MCP:** Not available |
| Profile Email Contacts | Number of taps on the email button on the account's profile. Deprecated by Meta.<br/><br/>**Field name:** `instagram_email_contacts`<br/>**Type:** metric<br/>**MCP:** Not available |
| Profile text message clicks | Number of taps on the text message button on the account's profile. Deprecated by Meta.<br/><br/>**Field name:** `instagram_text_message_clicks`<br/>**Type:** metric<br/>**MCP:** Not available |
| Profile website clicks | Number of taps on the website link in the account's profile bio. Deprecated by Meta.<br/><br/>**Field name:** `instagram_website_clicks`<br/>**Type:** metric<br/>**MCP:** Not available |
| Profile get directions clicks | Number of taps on the directions button on the account's profile. Deprecated by Meta.<br/><br/>**Field name:** `instagram_get_directions_clicks`<br/>**Type:** metric<br/>**MCP:** Not available |
| Media video views | Number of times a video media object was viewed. Deprecated by Meta in favor of 'views'.<br/><br/>**Field name:** `instagram_media_video_views`<br/>**Type:** metric<br/>**MCP:** Not available |
| Media Impressions | Total number of times the media object has been seen. Deprecated by Meta for media created after July 2, 2024.<br/><br/>**Field name:** `instagram_media_insight_impressions`<br/>**Type:** metric<br/>**MCP:** Not available |
| Reels replays count | Number of times the reel was replayed. Deprecated by Meta.<br/><br/>**Field name:** `instagram_media_reels_replays_count`<br/>**Type:** metric<br/>**MCP:** Not available |
| Reels plays | Number of times the reel was played. Deprecated by Meta in favor of 'views'.<br/><br/>**Field name:** `instagram_media_reels_plays`<br/>**Type:** metric<br/>**MCP:** Not available |
| Posts plays | Number of times the feed post's video was played.<br/><br/>**Field name:** `instagram_media_posts_plays`<br/>**Type:** metric<br/>**MCP:** Not available |
| Posts Impressions | Total number of times the feed post has been seen. Deprecated by Meta.<br/><br/>**Field name:** `instagram_media_posts_insight_impressions`<br/>**Type:** metric<br/>**MCP:** Not available |
