This reference covers the 99 dimensions available for Shopify in Master Metrics. Use it to understand how you can segment your data and how each field is named.

**Available in:** Dashboards · Reports · AI assistant · MCP

## Dimensions

Dimensions are the attributes you can use to segment and group your Shopify data.

### General

| | |
|---|---|
| Day | **Field name:** `day`<br/>**Type:** dimension |
| Week | **Field name:** `week`<br/>**Type:** dimension |
| Month | **Field name:** `month`<br/>**Type:** dimension |
| Year | **Field name:** `year`<br/>**Type:** dimension |
| Quarter | **Field name:** `quarter`<br/>**Type:** dimension |
| Store Name | Name of the store.<br/><br/>**Field name:** `shopify_shop_name`<br/>**Type:** dimension |
| Store ID | **Field name:** `shopify_shop_id`<br/>**Type:** dimension |
