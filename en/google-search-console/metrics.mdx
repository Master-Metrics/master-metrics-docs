This reference covers the 8 metrics available for Google Search Console in Master Metrics. Use it to understand which data you can pull and how each field is named.

**Available in:** Dashboards · Reports · AI assistant · MCP

## Metrics

Metrics are the numeric values you can measure and aggregate from your Google Search Console data.

### Search performance

| | |
|---|---|
| Impressions | **Field name:** `gsc_impressions`<br/>**Type:** metric<br/>**MCP:** Available |
| Clicks | **Field name:** `gsc_clicks`<br/>**Type:** metric<br/>**MCP:** Available |
| CTR | **Field name:** `gsc_ctr`<br/>**Type:** metric<br/>**MCP:** Available |
| Average position | **Field name:** `gsc_position`<br/>**Type:** metric<br/>**MCP:** Available |
| Words in search query | **Field name:** `gsc_words_in_query_met`<br/>**Type:** metric<br/>**MCP:** Available |

### Sitemaps

| | |
|---|---|
| Submitted URLs | **Field name:** `gsc_submitted`<br/>**Type:** metric<br/>**MCP:** Available |
| Warnings | **Field name:** `gsc_warnings`<br/>**Type:** metric<br/>**MCP:** Available |
| Errors | **Field name:** `gsc_errors`<br/>**Type:** metric<br/>**MCP:** Available |
