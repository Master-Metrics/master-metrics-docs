This reference covers the 33 dimensions available for Facebook Pages in Master Metrics. Use it to understand how you can segment your data and how each field is named.

**Available in:** Dashboards · Reports · AI assistant · MCP

## Dimensions

Dimensions are the attributes you can use to segment and group your Facebook Pages data.

### Page

| | |
|---|---|
| Page name | **Field name:** `PAGE_NAME`<br/>**Type:** dimension |
| Page ID | **Field name:** `PAGE_ID`<br/>**Type:** dimension |
| Language | **Field name:** `LANGUAGE`<br/>**Type:** dimension |
| Gender & Age (Deprecated) | **Field name:** `GENDERAGE`<br/>**Type:** dimension |
| Gender (Deprecated) | **Field name:** `GENDER_Deprecated`<br/>**Type:** dimension |
| Age (Deprecated) | **Field name:** `AGE_Deprecated`<br/>**Type:** dimension |
| Post Type | **Field name:** `POST_TYPE`<br/>**Type:** dimension |
| Post Media Type | **Field name:** `POST_MEDIA_TYPE`<br/>**Type:** dimension |
| Action Type | **Field name:** `ACTION_TYPE`<br/>**Type:** dimension |
