Esta referencia cubre las 25 dimensiones disponibles de TikTok Organic en Master Metrics. Úsala para entender cómo puedes segmentar tus datos y cómo se llama cada campo.

**Disponible en:** Dashboards · Reportes · Asistente de IA · MCP

## Dimensiones

Las dimensiones son los atributos que puedes usar para segmentar y agrupar tus datos de TikTok Organic.

### Tiempo

| | |
|---|---|
| Día | **Nombre del campo:** `day`<br/>**Tipo:** dimensión |
| Semana | **Nombre del campo:** `week`<br/>**Tipo:** dimensión |
| Mes | **Nombre del campo:** `month`<br/>**Tipo:** dimensión |
| Trimestre | **Nombre del campo:** `quarter`<br/>**Tipo:** dimensión |
| Año | **Nombre del campo:** `year`<br/>**Tipo:** dimensión |

### General

| | |
|---|---|
| Id de la cuenta | **Nombre del campo:** `tiktok_organic_account_id`<br/>**Tipo:** dimensión |
| Nombre de la cuenta | **Nombre del campo:** `tiktok_organic_account_name`<br/>**Tipo:** dimensión |
| Nombre del perfil | **Nombre del campo:** `tiktok_organic_profile_name`<br/>**Tipo:** dimensión |
| Nombre de usuario | **Nombre del campo:** `tiktok_organic_username`<br/>**Tipo:** dimensión |
| URL de la imagen de perfil | **Nombre del campo:** `tiktok_organic_profile_image_url`<br/>**Tipo:** dimensión |
| Tipo de cuenta | **Nombre del campo:** `tiktok_organic_account_type`<br/>**Tipo:** dimensión |
| Biografía | **Nombre del campo:** `tiktok_organic_bio`<br/>**Tipo:** dimensión |
| Verificada | **Nombre del campo:** `tiktok_organic_verified`<br/>**Tipo:** dimensión |
| URL del perfil | **Nombre del campo:** `tiktok_organic_profile_url`<br/>**Tipo:** dimensión |

### Videos

| | |
|---|---|
| ID del video | **Nombre del campo:** `tiktok_organic_video_id`<br/>**Tipo:** dimensión |
| Descripción del video | **Nombre del campo:** `tiktok_organic_video_caption`<br/>**Tipo:** dimensión |
| Fecha de publicación del video | **Nombre del campo:** `tiktok_organic_video_publish_date`<br/>**Tipo:** dimensión |
| URL para compartir del video | **Nombre del campo:** `tiktok_organic_video_share_url`<br/>**Tipo:** dimensión |
| URL de inserción del video | **Nombre del campo:** `tiktok_organic_video_embed_url`<br/>**Tipo:** dimensión |
