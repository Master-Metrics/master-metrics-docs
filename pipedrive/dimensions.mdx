Esta referencia cubre las 24 dimensiones disponibles de Pipedrive en Master Metrics. Úsala para entender cómo puedes segmentar tus datos y cómo se llama cada campo.

**Disponible en:** Dashboards · Reportes · Asistente de IA · MCP

## Dimensiones

Las dimensiones son los atributos que puedes usar para segmentar y agrupar tus datos de Pipedrive.

### Tiempo

| | |
|---|---|
| Día | **Nombre del campo:** `day`<br/>**Tipo:** dimensión |
| Semana | **Nombre del campo:** `week`<br/>**Tipo:** dimensión |
| Mes | **Nombre del campo:** `month`<br/>**Tipo:** dimensión |
| Año | **Nombre del campo:** `year`<br/>**Tipo:** dimensión |
| Trimestre | **Nombre del campo:** `quarter`<br/>**Tipo:** dimensión |

### Leads

| | |
|---|---|
| Nombre del creador | **Nombre del campo:** `creatorName`<br/>**Tipo:** dimensión |
| Fue visto | **Nombre del campo:** `seen`<br/>**Tipo:** dimensión |
| Nombre del responsable | **Nombre del campo:** `ownerName`<br/>**Tipo:** dimensión |
| Origen del lead | **Nombre del campo:** `sourceOrigin`<br/>**Tipo:** dimensión |
