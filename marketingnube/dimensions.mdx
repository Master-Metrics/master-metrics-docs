Esta referencia cubre las 21 dimensiones disponibles de Marketing Nube en Master Metrics. Úsala para entender cómo puedes segmentar tus datos y cómo se llama cada campo.

**Disponible en:** Dashboards · Reportes · Asistente de IA · MCP

## Dimensiones

Las dimensiones son los atributos que puedes usar para segmentar y agrupar tus datos de Marketing Nube.

### Tiempo

| | |
|---|---|
| Día | **Nombre del campo:** `day`<br/>**Tipo:** dimensión |
| Semana | **Nombre del campo:** `week`<br/>**Tipo:** dimensión |
| Mes | **Nombre del campo:** `month`<br/>**Tipo:** dimensión |
| Año | **Nombre del campo:** `year`<br/>**Tipo:** dimensión |
| Trimestre | **Nombre del campo:** `quarter`<br/>**Tipo:** dimensión |
| ID de cuenta | **Nombre del campo:** `mn_account_id`<br/>**Tipo:** dimensión |

### Campañas

| | |
|---|---|
| Fecha de envío de la campaña | **Nombre del campo:** `mn_campaign_send_date`<br/>**Tipo:** dimensión |
| Nombre de la campaña | **Nombre del campo:** `mn_campaign_name`<br/>**Tipo:** dimensión |
| Id de la campaña | **Nombre del campo:** `mn_campaign_id`<br/>**Tipo:** dimensión |
| Audiencia de la campaña | **Nombre del campo:** `mn_campaign_audience`<br/>**Tipo:** dimensión |
| URL del enlace de la campaña | **Nombre del campo:** `mn_campaign_link_url`<br/>**Tipo:** dimensión |
| Asunto de la campaña | **Nombre del campo:** `mn_campaign_subject`<br/>**Tipo:** dimensión |
| Email del remitente de la campaña | **Nombre del campo:** `mn_campaign_sender_email`<br/>**Tipo:** dimensión |
| Etiquetas de la campaña | **Nombre del campo:** `mn_campaign_tags`<br/>**Tipo:** dimensión |

### Automatizaciones

| | |
|---|---|
| Nombre de la automatización | **Nombre del campo:** `mn_automation_name`<br/>**Tipo:** dimensión |

### Contactos

| | |
|---|---|
| Id del contacto | **Nombre del campo:** `mn_contact_id`<br/>**Tipo:** dimensión |
| Nombre del contacto | **Nombre del campo:** `mn_contact_name`<br/>**Tipo:** dimensión |
| Email del contacto | **Nombre del campo:** `mn_contact_email`<br/>**Tipo:** dimensión |
| Fecha de alta del contacto | **Nombre del campo:** `mn_contact_created_date`<br/>**Tipo:** dimensión |
| Estado del contacto | **Nombre del campo:** `mn_contact_status`<br/>**Tipo:** dimensión |
| Origen del contacto | **Nombre del campo:** `mn_contact_source`<br/>**Tipo:** dimensión |
