Esta referência cobre as 44 dimensões disponíveis de Meta Ads no Master Metrics. Use-a para entender como você pode segmentar seus dados e como cada campo se chama.

**Disponível em:** Dashboards · Relatórios · Assistente de IA · MCP

## Dimensões

As dimensões são os atributos que você pode usar para segmentar e agrupar seus dados de Meta Ads.
