Esta referência cobre as 8 métricas disponíveis de Kommo no Master Metrics. Use-a para entender quais dados você pode obter e como cada campo se chama.

**Disponível em:** Dashboards · Relatórios · Assistente de IA · MCP

## Métricas

As métricas são os valores numéricos que você pode medir e agregar a partir dos seus dados de Kommo.

### Leads

| | |
|---|---|
| Contagem de Leads | **Nome do campo:** `lead_count`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Valor de Leads $ | **Nome do campo:** `won_leads_acc_price`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Tempo médio de venda | **Nome do campo:** `avg_lead_sales_time`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Tempo médio de fechamento | **Nome do campo:** `avg_lead_close_time`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |

### Contatos

| | |

### Empresas
