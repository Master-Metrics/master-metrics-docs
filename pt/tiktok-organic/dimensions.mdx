Esta referência cobre as 25 dimensões disponíveis de TikTok Organic no Master Metrics. Use-a para entender como você pode segmentar seus dados e como cada campo se chama.

## Dimensões

As dimensões são os atributos que você pode usar para segmentar e agrupar seus dados de TikTok Organic.

|---|---|
| Dia | **Nome do campo:** `day`<br/>**Tipo:** dimensão |
| Semana | **Nome do campo:** `week`<br/>**Tipo:** dimensão |
| Mês | **Nome do campo:** `month`<br/>**Tipo:** dimensão |
| Trimestre | **Nome do campo:** `quarter`<br/>**Tipo:** dimensão |
| Ano | **Nome do campo:** `year`<br/>**Tipo:** dimensão |
