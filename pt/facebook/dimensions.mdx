Esta referência cobre as 33 dimensões disponíveis de Facebook Pages no Master Metrics. Use-a para entender como você pode segmentar seus dados e como cada campo se chama.

**Disponível em:** Dashboards · Relatórios · Assistente de IA · MCP

## Dimensões

As dimensões são os atributos que você pode usar para segmentar e agrupar seus dados de Facebook Pages.

### Página

| | |
|---|---|
| Nome da página | **Nome do campo:** `PAGE_NAME`<br/>**Tipo:** dimensão |
| ID da página | **Nome do campo:** `PAGE_ID`<br/>**Tipo:** dimensão |
| Idioma | **Nome do campo:** `LANGUAGE`<br/>**Tipo:** dimensão |
| Gênero e Idade (Obsoleto) | **Nome do campo:** `GENDERAGE`<br/>**Tipo:** dimensão |
| Gênero (Obsoleto) | **Nome do campo:** `GENDER_Deprecated`<br/>**Tipo:** dimensão |
| Idade (Obsoleto) | **Nome do campo:** `AGE_Deprecated`<br/>**Tipo:** dimensão |
| Tipo de publicação | **Nome do campo:** `POST_TYPE`<br/>**Tipo:** dimensão |
| Tipo de mídia da publicação | **Nome do campo:** `POST_MEDIA_TYPE`<br/>**Tipo:** dimensão |
| Tipo de ação | **Nome do campo:** `ACTION_TYPE`<br/>**Tipo:** dimensão |
