title: "Catálogo de campos"
description: "Explore todas as métricas e dimensões disponíveis para cada fonte de dados"
---

Cada fonte de dados conectada ao Master Metrics expõe um conjunto de campos que você pode usar em seus dashboards, relatórios e conversas com IA. Os campos são de dois tipos:

- **Métricas**: os números que você mede, como impressões, alcance, pedidos ou receita.
- **Dimensões**: as categorias pelas quais você agrupa, como data, país, tipo de conteúdo ou produto.

Use este catálogo para encontrar os campos exatos disponíveis em cada fonte. Cada campo mostra seu nome, seu nome de campo e uma breve descrição, além de indicar se pode ser consultado pela integração MCP para ferramentas de IA.
