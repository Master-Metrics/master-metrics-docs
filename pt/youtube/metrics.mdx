Esta referência cobre as 23 métricas disponíveis de YouTube no Master Metrics. Use-a para entender quais dados você pode obter e como cada campo se chama.

**Disponível em:** Dashboards · Relatórios · Assistente de IA · MCP

## Métricas

As métricas são os valores numéricos que você pode medir e agregar a partir dos seus dados de YouTube.

### Canal

| | |
|---|---|
| Contagem total de visualizações do canal | **Nome do campo:** `youtube_channel_views`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Total de inscritos no canal | **Nome do campo:** `youtube_channel_subscribers`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Total de vídeos do canal | **Nome do campo:** `youtube_channel_videos`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Inscritos ganhos | **Nome do campo:** `youtube_subscribersGained`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Inscritos perdidos | **Nome do campo:** `youtube_subscribersLost`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Minutos estimados assistidos | **Nome do campo:** `youtube_estimatedMinutesWatched`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Proporção de visualização da audiência | **Nome do campo:** `youtube_audienceWatchRatio`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Visualizações | **Nome do campo:** `youtube_views`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Comentários | **Nome do campo:** `youtube_comments`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |

| Não curtidas | **Nome do campo:** `youtube_dislikes`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Compartilhamentos | **Nome do campo:** `youtube_shares`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
