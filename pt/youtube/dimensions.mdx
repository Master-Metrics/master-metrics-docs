Esta referência cobre as 40 dimensões disponíveis de YouTube no Master Metrics. Use-a para entender como você pode segmentar seus dados e como cada campo se chama.

**Disponível em:** Dashboards · Relatórios · Assistente de IA · MCP

## Dimensões

As dimensões são os atributos que você pode usar para segmentar e agrupar seus dados de YouTube.

| | |
|---|---|
| Dia | **Nome do campo:** `day`<br/>**Tipo:** dimensão |
| Semana | **Nome do campo:** `week`<br/>**Tipo:** dimensão |
| Mês | **Nome do campo:** `month`<br/>**Tipo:** dimensão |
| Ano | **Nome do campo:** `year`<br/>**Tipo:** dimensão |
