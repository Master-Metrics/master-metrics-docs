Esta referência cobre as 99 dimensões disponíveis de Shopify no Master Metrics. Use-a para entender como você pode segmentar seus dados e como cada campo se chama.

**Disponível em:** Dashboards · Relatórios · Assistente de IA · MCP

## Dimensões

As dimensões são os atributos que você pode usar para segmentar e agrupar seus dados de Shopify.

### Geral

| | |
|---|---|
| Dia | **Nome do campo:** `day`<br/>**Tipo:** dimensão |
| Semana | **Nome do campo:** `week`<br/>**Tipo:** dimensão |
| Mês | **Nome do campo:** `month`<br/>**Tipo:** dimensão |
| Ano | **Nome do campo:** `year`<br/>**Tipo:** dimensão |
| Trimestre | **Nome do campo:** `quarter`<br/>**Tipo:** dimensão |
| Nome da Loja | Nome da loja.<br/><br/>**Nome do campo:** `shopify_shop_name`<br/>**Tipo:** dimensão |
| ID da Loja | **Nome do campo:** `shopify_shop_id`<br/>**Tipo:** dimensão |
| Nome da Entidade | **Nome do campo:** `shopify_entity_name`<br/>**Tipo:** dimensão |
