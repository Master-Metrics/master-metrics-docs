<Info>**Última atualização:** 2026-11-12</Info>

Esta referência cobre as 87 métricas disponíveis de Shopify no Master Metrics. Use-a para entender quais dados você pode obter e como cada campo se chama.

**Disponível em:** Dashboards · Relatórios · Assistente de IA · MCP

## Métricas

As métricas são os valores numéricos que você pode medir e agregar a partir dos seus dados de Shopify.

### Clientes

| | |
|---|---|
| Contagem (Clientes) | Quantidade de clientes da loja.<br/><br/>**Nome do campo:** `shopify_customers_count`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |

### Carrinhos abandonados

| | |
|---|---|
| Contagem (Finalizações Abandonadas) | Quantidade de checkouts abandonados.<br/><br/>**Nome do campo:** `shopify_abandonedCheckouts_count`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Valor Total (Finalizações Abandonadas) | Valor total dos checkouts abandonados.<br/><br/>**Nome do campo:** `shopify_abandonedCheckouts_total_amount`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |

| | |

| Contagem (Pedidos) | Quantidade de pedidos.<br/><br/>**Nome do campo:** `shopify_orders_count`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |

| Taxas Totais (Pedidos) | Taxas adicionais cobradas nos pedidos.<br/><br/>**Nome do campo:** `shopify_orders_fees`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Descontos Totais (Pedidos) | Descontos totais aplicados aos produtos dos pedidos.<br/><br/>**Nome do campo:** `shopify_orders_discounts`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Custo de Envio (Pedidos) | Frete cobrado nos pedidos.<br/><br/>**Nome do campo:** `shopify_orders_original_price`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Taxas Alfandegárias Totais (Pedidos) | Tarifas alfandegárias cobradas nos pedidos.<br/><br/>**Nome do campo:** `shopify_orders_duties`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Preço Total (Pedidos) | Preço total atual dos pedidos, depois de edições e reembolsos.<br/><br/>**Nome do campo:** `shopify_orders_price`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Preço Médio (Pedidos) | Valor médio do pedido: vendas divididas pela quantidade de pedidos.<br/><br/>**Nome do campo:** `shopify_orders_average_price`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Subtotal Total (Pedidos) | Preço dos pedidos depois dos descontos, antes de frete e impostos.<br/><br/>**Nome do campo:** `shopify_orders_subtotal_price`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Impostos (Pedidos) | Impostos cobrados nos pedidos.<br/><br/>**Nome do campo:** `shopify_orders_tax`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Devoluções (Pedidos) | Valor dos produtos devolvidos.<br/><br/>**Nome do campo:** `shopify_orders_returns_total`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Impostos de Devoluções (Pedidos) | Impostos dos produtos devolvidos.<br/><br/>**Nome do campo:** `shopify_orders_returns_taxes`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Vendas líquidas (Pedidos) | Vendas líquidas: vendas brutas menos descontos e devoluções. Sem frete nem impostos.<br/><br/>**Nome do campo:** `shopify_orders_net_sales_total`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Vendas totais (Pedidos) | Vendas totais: vendas líquidas mais frete, impostos, tarifas alfandegárias e taxas.<br/><br/>**Nome do campo:** `shopify_orders_total_sales`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Itens Líquidos Vendidos (Pedidos) | Itens líquidos vendidos: unidades vendidas menos unidades devolvidas. Usar para produtos vendidos.<br/><br/>**Nome do campo:** `shopify_orders_net_items_sold`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Custo de Mercadorias Vendidas (Pedidos) | Custo dos produtos vendidos, para produtos com custo cadastrado.<br/><br/>**Nome do campo:** `shopify_orders_cost_of_goods_sold`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Margem Bruta (Pedidos) | Margem bruta: lucro bruto como porcentagem das vendas líquidas com custo cadastrado.<br/><br/>**Nome do campo:** `shopify_orders_gross_margin`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Lucro Bruto (Pedidos) | Lucro bruto: vendas líquidas de produtos com custo cadastrado menos o seu custo.<br/><br/>**Nome do campo:** `shopify_orders_gross_profit`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Valor Gasto por Cliente (Pedidos) | Valor médio gasto por cliente.<br/><br/>**Nome do campo:** `shopify_orders_amount_spent_per_customer`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Pacotes Pedidos (Pedidos) | Quantidade de kits de produtos pedidos.<br/><br/>**Nome do campo:** `shopify_orders_bundles_ordered`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Clientes (Pedidos) | Quantidade de clientes que fizeram pedidos.<br/><br/>**Nome do campo:** `shopify_orders_customers`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Descontos Devolvidos (Pedidos) | Descontos revertidos por devoluções.<br/><br/>**Nome do campo:** `shopify_orders_discounts_returned`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Descontos de Cartão Presente (Pedidos) | Descontos aplicados a cartões-presente.<br/><br/>**Nome do campo:** `shopify_orders_gift_card_discounts`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Vendas Brutas de Cartão Presente (Pedidos) | Vendas brutas de cartões-presente.<br/><br/>**Nome do campo:** `shopify_orders_gift_card_gross_sales`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Vendas Líquidas de Cartão Presente (Pedidos) | Vendas líquidas de cartões-presente.<br/><br/>**Nome do campo:** `shopify_orders_gift_card_net_sales`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Impostos de Cartão Presente (Pedidos) | Impostos cobrados sobre cartões-presente.<br/><br/>**Nome do campo:** `shopify_orders_gift_card_taxes`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Devoluções Brutas (Pedidos) | Valor bruto dos produtos devolvidos.<br/><br/>**Nome do campo:** `shopify_orders_gross_returns`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |

| Devoluções Líquidas (Pedidos) | Valor dos produtos devolvidos, líquido dos seus descontos.<br/><br/>**Nome do campo:** `shopify_orders_net_returns`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Vendas Líquidas com Custo Registrado (Pedidos) | Vendas líquidas de produtos com custo cadastrado.<br/><br/>**Nome do campo:** `shopify_orders_net_sales_with_cost_recorded`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Vendas Líquidas sem Custo Registrado (Pedidos) | Vendas líquidas de produtos sem custo cadastrado.<br/><br/>**Nome do campo:** `shopify_orders_net_sales_without_cost_recorded`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Novos Clientes (Pedidos) | Quantidade de clientes que compraram pela primeira vez.<br/><br/>**Nome do campo:** `shopify_orders_new_customers`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |

| Impostos de Taxa de Envio (Pedidos) | Impostos cobrados sobre o frete.<br/><br/>**Nome do campo:** `shopify_orders_shipping_charge_taxes`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |

| Contagem (Transações) | Quantidade de transações de pagamento (vendas, autorizações, reembolsos...).<br/><br/>**Nome do campo:** `shopify_transactions_count`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Valor Total (Transações) | Valor total das transações de pagamento.<br/><br/>**Nome do campo:** `shopify_transactions_total_amount`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |

| Quantidade Atual Total de Produto (Pedidos) | Unidades atuais de produtos nos pedidos, depois de remoções e devoluções.<br/><br/>**Nome do campo:** `shopify_orders_line_items_current_quantity`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |

| Duração média da sessão (Sessões) | Duração média das sessões.<br/><br/>**Nome do campo:** `shopify_sessions_average_session_duration`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Taxa de adição ao carrinho (Sessões) | Porcentagem de sessões que adicionaram um produto ao carrinho.<br/><br/>**Nome do campo:** `shopify_sessions_added_to_cart_rate`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
