Esta referência cobre as 8 métricas disponíveis de Google Search Console no Master Metrics. Use-a para entender quais dados você pode obter e como cada campo se chama.

**Disponível em:** Dashboards · Relatórios · Assistente de IA · MCP

## Métricas

As métricas são os valores numéricos que você pode medir e agregar a partir dos seus dados de Google Search Console.

### Desempenho de pesquisa

| | |
|---|---|
| Impressões | **Nome do campo:** `gsc_impressions`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Cliques | **Nome do campo:** `gsc_clicks`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| CTR | **Nome do campo:** `gsc_ctr`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Posição média | **Nome do campo:** `gsc_position`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Palavras na consulta de pesquisa | **Nome do campo:** `gsc_words_in_query_met`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |

### Sitemaps

| | |
|---|---|
| URLs enviadas | **Nome do campo:** `gsc_submitted`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Avisos | **Nome do campo:** `gsc_warnings`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Erros | **Nome do campo:** `gsc_errors`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
