Esta referência cobre as 27 dimensões disponíveis de Google Search Console no Master Metrics. Use-a para entender como você pode segmentar seus dados e como cada campo se chama.

**Disponível em:** Dashboards · Relatórios · Assistente de IA · MCP

## Dimensões

As dimensões são os atributos que você pode usar para segmentar e agrupar seus dados de Google Search Console.

### Tempo

| | |
|---|---|
| Dia | **Nome do campo:** `day`<br/>**Tipo:** dimensão |
| Semana | **Nome do campo:** `week`<br/>**Tipo:** dimensão |
| Mês | **Nome do campo:** `month`<br/>**Tipo:** dimensão |
| Trimestre | **Nome do campo:** `quarter`<br/>**Tipo:** dimensão |
| Ano | **Nome do campo:** `year`<br/>**Tipo:** dimensão |

### Geral

| | |
|---|---|
| Propriedade de Domínio | **Nome do campo:** `gsc_account_id`<br/>**Tipo:** dimensão |

|---|---|

| Nº de palavras na consulta | **Nome do campo:** `gsc_words_in_query`<br/>**Tipo:** dimensão |
| Tipo de pesquisa | **Nome do campo:** `gsc_searchtype`<br/>**Tipo:** dimensão |
| Aparência na pesquisa | **Nome do campo:** `gsc_searchappearance`<br/>**Tipo:** dimensão |
