Esta referência cobre as 7 métricas disponíveis de GoHighLevel no Master Metrics. Use-a para entender quais dados você pode obter e como cada campo se chama.

**Disponível em:** Dashboards · Relatórios · Assistente de IA · MCP

## Métricas

As métricas são os valores numéricos que você pode medir e agregar a partir dos seus dados de GoHighLevel.

### Contatos

| | |
|---|---|
| Contagem (Contatos) | **Nome do campo:** `ghl_contact_count`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |

### Oportunidades

| | |
|---|---|
| Contagem (Oportunidades) | **Nome do campo:** `ghl_opportunity_count`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Valor Monetário (Oportunidades) | **Nome do campo:** `ghl_opportunity_monetary_value`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Média de dias desde a última atualização (Oportunidades) | **Nome do campo:** `ghl_opportunity_avg_days_since_last_update`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Média de dias desde a última mudança de status (Oportunidades) | **Nome do campo:** `ghl_opportunity_avg_days_since_last_status_change`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Média de dias desde a última mudança de etapa (Oportunidades) | **Nome do campo:** `ghl_opportunity_avg_days_since_last_stage_change`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
