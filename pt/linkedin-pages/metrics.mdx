Esta referência cobre as 23 métricas disponíveis de LinkedIn Pages no Master Metrics. Use-a para entender quais dados você pode obter e como cada campo se chama.

**Disponível em:** Dashboards · Relatórios · Assistente de IA

## Métricas

As métricas são os valores numéricos que você pode medir e agregar a partir dos seus dados de LinkedIn Pages.

| | |
|---|---|
| Seguidores | **Nome do campo:** `lcp_follower_count`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Seguidores orgânicos | **Nome do campo:** `lcp_follower_count_organic`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Novos seguidores | **Nome do campo:** `lcp_followers_gain_total`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Novos seguidores orgânicos | **Nome do campo:** `lcp_followers_gain_organic`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
