Esta referência cobre as 22 dimensões disponíveis de LinkedIn Pages no Master Metrics. Use-a para entender como você pode segmentar seus dados e como cada campo se chama.

**Disponível em:** Dashboards · Relatórios · Assistente de IA

## Dimensões

As dimensões são os atributos que você pode usar para segmentar e agrupar seus dados de LinkedIn Pages.

### Tempo

| | |
|---|---|
| Dia | **Nome do campo:** `day`<br/>**Tipo:** dimensão |
| Semana | **Nome do campo:** `week`<br/>**Tipo:** dimensão |
| Mês | **Nome do campo:** `month`<br/>**Tipo:** dimensão |
| Trimestre | **Nome do campo:** `quarter`<br/>**Tipo:** dimensão |
| Ano | **Nome do campo:** `year`<br/>**Tipo:** dimensão |

### Geral

| | |
|---|---|
| ID da conta | **Nome do campo:** `lcp_account_id`<br/>**Tipo:** dimensão |
| Nome da conta | **Nome do campo:** `lcp_account_name`<br/>**Tipo:** dimensão |
