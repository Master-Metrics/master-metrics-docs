Esta referência cobre as 13 métricas disponíveis de Pipedrive no Master Metrics. Use-a para entender quais dados você pode obter e como cada campo se chama.

**Disponível em:** Dashboards · Relatórios · Assistente de IA · MCP

## Métricas

As métricas são os valores numéricos que você pode medir e agregar a partir dos seus dados de Pipedrive.

### Leads

| | |
|---|---|
| Contagem de Leads | **Nome do campo:** `lead_count`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Valor Total dos Leads | **Nome do campo:** `sum_lead_value`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
| Valor Médio dos Leads | **Nome do campo:** `avg_lead_value`<br/>**Tipo:** métrica<br/>**MCP:** Disponível |
