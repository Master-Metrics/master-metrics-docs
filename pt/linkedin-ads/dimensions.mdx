Esta referência cobre as 33 dimensões disponíveis de LinkedIn Ads no Master Metrics. Use-a para entender como você pode segmentar seus dados e como cada campo se chama.

**Disponível em:** Dashboards · Relatórios · Assistente de IA · MCP

## Dimensões

As dimensões são os atributos que você pode usar para segmentar e agrupar seus dados de LinkedIn Ads.

### Geral

| | |
|---|---|
| Nome da Conta | **Nome do campo:** `ACCOUNT_NAME`<br/>**Tipo:** dimensão |
| ID da Conta | **Nome do campo:** `ACCOUNT_ID`<br/>**Tipo:** dimensão |
| Nome da Campanha | **Nome do campo:** `CAMPAIGN_NAME`<br/>**Tipo:** dimensão |
| Status da Campanha | **Nome do campo:** `CAMPAIGN_STATUS`<br/>**Tipo:** dimensão |
| ID da Campanha | **Nome do campo:** `CAMPAIGN_ID`<br/>**Tipo:** dimensão |
| Tipo de Campanha | **Nome do campo:** `CAMPAIGN_TYPE`<br/>**Tipo:** dimensão |
| Nome do Grupo de Campanha | **Nome do campo:** `CAMPAIGN_GROUP_NAME`<br/>**Tipo:** dimensão |
| Status do Grupo de Campanha | **Nome do campo:** `CAMPAIGN_GROUP_STATUS`<br/>**Tipo:** dimensão |
| ID do Grupo de Campanha | **Nome do campo:** `CAMPAIGN_GROUP_ID`<br/>**Tipo:** dimensão |
| Indústria | **Nome do campo:** `MEMBER_INDUSTRY`<br/>**Tipo:** dimensão |
| Nome da Conversão | **Nome do campo:** `CONVERSION_NAME`<br/>**Tipo:** dimensão |
| ID da Conversão | **Nome do campo:** `CONVERSION_ID`<br/>**Tipo:** dimensão |
| Tipo de Conversão | **Nome do campo:** `CONVERSION_TYPE`<br/>**Tipo:** dimensão |
| Conversão Ativada | **Nome do campo:** `CONVERSION_ENABLED`<br/>**Tipo:** dimensão |
| Tamanho da empresa | **Nome do campo:** `MEMBER_COMPANY_SIZE`<br/>**Tipo:** dimensão |
| Níveis hierárquicos | **Nome do campo:** `MEMBER_SENIORITY`<br/>**Tipo:** dimensão |
| Título do cargo | **Nome do campo:** `MEMBER_JOB_TITLE`<br/>**Tipo:** dimensão |
| Função do cargo | **Nome do campo:** `MEMBER_JOB_FUNCTION`<br/>**Tipo:** dimensão |
| País | **Nome do campo:** `MEMBER_COUNTRY_V2`<br/>**Tipo:** dimensão |
| Regiões | **Nome do campo:** `MEMBER_REGION_V2`<br/>**Tipo:** dimensão |
| Empresa | **Nome do campo:** `MEMBER_COMPANY`<br/>**Tipo:** dimensão |
| Nome do Criativo | **Nome do campo:** `CREATIVE_NAME`<br/>**Tipo:** dimensão |
