Esta referencia cubre las 23 métricas disponibles de LinkedIn Pages en Master Metrics. Úsala para entender qué datos puedes obtener y cómo se llama cada campo.

**Disponible en:** Dashboards · Reportes · Asistente de IA

## Métricas

Las métricas son los valores numéricos que puedes medir y agregar a partir de tus datos de LinkedIn Pages.

### Seguidores

| | |
|---|---|
| Seguidores | **Nombre del campo:** `lcp_follower_count`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Seguidores orgánicos | **Nombre del campo:** `lcp_follower_count_organic`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Nuevos seguidores | **Nombre del campo:** `lcp_followers_gain_total`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Nuevos seguidores orgánicos | **Nombre del campo:** `lcp_followers_gain_organic`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
| Nuevos seguidores patrocinados | **Nombre del campo:** `lcp_followers_gain_paid`<br/>**Tipo:** métrica<br/>**MCP:** Disponible |
