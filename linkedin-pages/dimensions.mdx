Esta referencia cubre las 22 dimensiones disponibles de LinkedIn Pages en Master Metrics. Úsala para entender cómo puedes segmentar tus datos y cómo se llama cada campo.

**Disponible en:** Dashboards · Reportes · Asistente de IA

## Dimensiones

Las dimensiones son los atributos que puedes usar para segmentar y agrupar tus datos de LinkedIn Pages.

### Tiempo

| | |
|---|---|
| Día | **Nombre del campo:** `day`<br/>**Tipo:** dimensión |
| Semana | **Nombre del campo:** `week`<br/>**Tipo:** dimensión |
| Mes | **Nombre del campo:** `month`<br/>**Tipo:** dimensión |
| Trimestre | **Nombre del campo:** `quarter`<br/>**Tipo:** dimensión |
| Año | **Nombre del campo:** `year`<br/>**Tipo:** dimensión |

### General

| | |
|---|---|
| ID de la cuenta | **Nombre del campo:** `lcp_account_id`<br/>**Tipo:** dimensión |
| Nombre de la cuenta | **Nombre del campo:** `lcp_account_name`<br/>**Tipo:** dimensión |

### Seguidores

| | |
|---|---|
| País del seguidor | **Nombre del campo:** `lcp_follower_country`<br/>**Tipo:** dimensión |
| Función laboral del seguidor | **Nombre del campo:** `lcp_follower_function`<br/>**Tipo:** dimensión |
| Región del seguidor | **Nombre del campo:** `lcp_follower_region`<br/>**Tipo:** dimensión |
| Industria del seguidor | **Nombre del campo:** `lcp_follower_industry`<br/>**Tipo:** dimensión |
| Tamaño de empresa del seguidor | **Nombre del campo:** `lcp_follower_company_size`<br/>**Tipo:** dimensión |
| Antigüedad del seguidor | **Nombre del campo:** `lcp_follower_seniority`<br/>**Tipo:** dimensión |
| Asociación del seguidor | **Nombre del campo:** `lcp_follower_association`<br/>**Tipo:** dimensión |
